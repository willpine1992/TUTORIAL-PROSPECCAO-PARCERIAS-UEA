# Guia da Prospecção de Parcerias · PROPESP/UEA

Tutorial em formato de revista para coordenações de PPG: como usar o painel de Prospecção (FAAP) para encontrar pesquisadores no exterior com afinidade às linhas de pesquisa da UEA.

## Como atualizar

1. Edite o `index.html` (é a fonte única: versão web e PDF).
2. Rode `zsh render.sh` para regerar o PDF a partir do HTML (Chrome headless).
3. `git add -A && git commit -m "..." && git push` — o GitHub Pages publica em ~1 minuto.
